# Good Teacher

[完整提示词 · 纯文本](good-teacher.txt) · [Markdown 版](PROMPT.md)

## 使用

1. 打开上面的纯文本文件，点击 **Raw** 并复制全部内容。
2. 粘贴到 AI 聊天中，并按引导介绍课程、基础、目标和教学偏好。
3. AI 生成专属教学提示词后，将产物用于原聊天或新聊天，提供实际课程资料后开始学习。

两个提示词文件内容相同，选择方便复制或阅读的格式即可。
